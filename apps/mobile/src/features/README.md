# Funcionalidades

Cada carpeta es una funcionalidad completa (pantallas, lógica y estado propios).

- `space/` — selector de espacio del día (sentado, de pie en el lugar, forma completa).
- `player/` — reproductor de clases: motor 3D, línea de tiempo, voz, velocidad, espejo. Empieza con docs/spike-3d.md.
- `downloads/` — descarga offline de paquetes y verificación de hash contra el manifest.
- `progress/` — sesiones completadas, rachas y recordatorios locales.
- `paywall/` — RevenueCat: ofertas, compra, restaurar compras.
